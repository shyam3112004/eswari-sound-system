# Doc 03: Product Requirements Document (PRD) — Eswari Sound System

## 1. Overview & Positioning

| Field | Content |
|---|---|
| **App Name** | Eswari Sound System |
| **Tagline** | Concert Audio, Flown Line Arrays & Stage Rigging Production |
| **Problem** | Event organizers, wedding planners, and festival committees routinely suffer from broker fraud, equipment bait-and-switch, under-powered audio setups, and uncalibrated feedback during live events because middlemen outsource to low-bid vendors. |
| **Value Proposition** | 100% single-provider ownership of all concert-grade line arrays, intelligent DMX lighting, and modular stage decks. Direct certified sound engineers, zero broker markups, and instant date lock with a 25% advance payment. |
| **Primary Persona** | High-end wedding planners, temple & college festival conveners, corporate event managers. |
| **Secondary Persona** | Independent touring bands, EDM DJs, and live acoustic music performers. |
| **Internal Persona** | Eswari Operations Manager, Lead FOH Audio Engineer, and Stage Rigging Supervisor. |

---

## 2. Core Features (Must Have — Phase 1 to Phase 9)

| # | Feature | Description |
|---|---|---|
| 1 | **Cinematic Frame-Scrub Homepage** | Pinned full-screen canvas scrubbing 6 video sections (48s seamless loop) via WebP frames inside defined safe zones. |
| 2 | **Transparent Gear & Package Catalog** | Pre-engineered stage setups (Basic Sound, Premium DJ, Stage Lighting, Mega Event) with breakdown of wattage, channels, and inclusions. |
| 3 | **Hybrid Booking Flow** | Instant 25% advance booking for standard packages with Razorpay integration + calendar date locking. |
| 4 | **Custom Festival / Concert Inquiry** | Tailored multi-day requirement builder with auto-calculation and admin custom quote response. |
| 5 | **Customer Booking & Invoice Lookup** | Self-service status check via phone/email, balance tracking, and downloadable receipt. |
| 6 | **Admin Operations Console** | Manage calendar blackout dates, approve inquiries, dispatch technical crew, and track payments. |

---

## 3. Nice to Have (v2) & Out of Scope (v1)

- **Nice to Have (v2):** Multi-stage interactive 3D venue layout visualizer, SMS WhatsApp webhook notifications via Twilio/Meta Business API, multi-currency payments for NRI wedding clients.
- **Out of Scope (v1):** Multi-vendor marketplace or external equipment leasing; customer user accounts with passwords (phone/email OTP verification used instead).

## 4. User Stories

| As a… | I want to… | So that… |
|---|---|---|
| **Event Organizer** | Visually explore the stage gear and line-array power | I can trust that the sound won't fail for 5,000+ attendees. |

## 5. Success Metrics (First 90 Days)

1. **Zero Double-Bookings:** 100% calendar lock accuracy with automatic slot reservation.
2. **Booking Conversion:** > 15% inquiry-to-advance payment conversion rate.
3. **Scroll Engagement:** > 75% average scroll depth on the canvas frame-scrub homepage.
4. **Direct Inquiries:** 40+ verified inquiries per month directly eliminating event broker commissions.
